# 키오스크 중앙관리 CMS

건물 곳곳에 설치한 여러 대의 키오스크를 **한 곳에서** 관리합니다.
- 평소에는 **홍보/광고(사진·동영상)** 를 순서대로 재생합니다.
- 누군가 화면을 터치하면 **건물(동)별 층별 안내**로 바뀌고, 일정 시간 조작이 없으면 다시 홍보 화면으로 돌아갑니다.
- 키오스크는 몇 대든 추가할 수 있고, 키오스크마다 건물(동), 재생목록, 노출 시간을 따로 설정합니다.

## 빠른 시작

```bash
npm install
npm run seed        # 데모 데이터(본관/세종관, 홍보물, 키오스크 3대). 초기화: npm run seed -- --force
cp .env.example .env  # .env 의 ADMIN_PASSWORD 에 관리자 비밀번호 입력
npm start
```

| 화면 | 주소 |
|---|---|
| 관리자 | `http://서버:3000/admin/` (비밀번호는 `.env`의 `ADMIN_PASSWORD`, 없으면 서버가 시작하지 않음) |
| 키오스크 | `http://서버:3000/k/<키오스크코드>` 예: `/k/main-lobby` |
| 미리보기 | `/k/<코드>?preview=1` (상태 보고를 하지 않음) |

환경변수: `PORT`(3000), `ADMIN_PASSWORD`, `DATA_DIR`(./data), `UPLOAD_DIR`(./uploads), `DB_FILE`

## 기능

화면 설계: `docs/screens.excalidraw` (excalidraw.com 에서 열기)

### 키오스크 화면 (세로형 1080×1920, 밝은 테마)
| 화면 | 내용 |
|---|---|
| 홍보 화면 | 사진은 지정한 초만큼 보여준 뒤 옆으로 넘김, 동영상은 끝까지 재생 후 다음. 터치하면 층별 안내로 |
| 층별 안내 | 동 탭 → 층 버튼 → 검색 → 분류 칩(아이콘: 관리자 분류 관리에서 선택, Lucide·ISC 라이선스) → 도면(시설 핀·현재 위치) → 시설 목록. 시설마다 운영 상태(운영 중·곧 종료·운영 종료·오늘 휴무) 자동 표시. 조작이 없으면 홍보 화면으로 복귀 |
| 다국어 | 상단 [English] 버튼으로 영어 전환(관리자가 입력한 영문 이름 사용, 없으면 한국어). 홍보 화면으로 돌아가면 한국어로 복귀 |
| 시설 상세 | 위치·분류·운영 상태·운영시간·연락처. ✕ 또는 바깥 터치로 닫기 |
| 검색 | 두벌식/영문 화상 키보드, 초성 검색, 시설명(영문 포함)·호실·키워드 검색 |
| 점검 중 | 등록되지 않은 코드이거나 관리자에서 “사용 안 함”일 때 |
| 하단 공지 | 관리자에서 등록한 공지가 흐르는 글로 표시 |

### 관리자
| 메뉴 | 내용 |
|---|---|
| 키오스크 | 추가·복제·삭제, 키오스크별 건물(동)·설치 층·현재 위치·재생목록·동작 모드(터치 가능/불가)·대기 복귀 초. 온라인 상태와 현재 재생 콘텐츠, 화면 안 [미리보기], 원격 [재시작] |
| 재생목록 | 사진·동영상 추가, 드래그로 순서 변경, 항목별 노출 초·소리·노출 여부, 기간·요일·시간대 예약 |
| 미디어 라이브러리 | 여러 파일 한 번에 업로드(드래그&드롭), 재생목록 간 재사용 |
| 시설 관리 | 동 → 층 → 시설 등록, 층 도면 업로드 후 클릭해서 시설 핀 지정, 요일별 운영시간(평일/토/일, 휴무·24시간), 영문 이름, 시설 일괄 입력(엑셀 붙여넣기, “평일 09:00-18:00 / 일 휴무” 같은 운영시간 글자는 자동 변환) |
| 공지 | 하단 흐르는 공지, 대상(전체/동/키오스크)·기간 지정 |

그 밖에: 저장 즉시 모든 키오스크에 실시간 반영(SSE), 서버 연결이 끊겨도 마지막 설정으로 계속 재생, 새벽 4시대 자동 새로고침, 동영상 멈춤 감시.

### 층 도면 준비
배경 제거(누끼)는 필요 없습니다. 평면도 이미지(JPG/PNG)를 바깥 여백만 잘라서 올리면 됩니다. 가로 1500px 이상, 방 이름 정도만 있는 단순한 그림(소방 대피도 같은)이 가장 보기 좋습니다. 자르는 범위가 다른 이미지로 교체하면 시설 핀을 다시 찍어야 합니다.

## 키오스크 기기 설정

키오스크 PC/미니PC/안드로이드 셋톱에서 Chrome을 전체화면 키오스크 모드로 띄웁니다.

```bash
# Windows/리눅스 예시: 시작 프로그램에 등록
chrome --kiosk --autoplay-policy=no-user-gesture-required --noerrdialogs --disable-translate \
  --disable-pinch --overscroll-history-navigation=0 http://서버:3000/k/main-lobby
```
- `--autoplay-policy=no-user-gesture-required`: 동영상 **소리** 재생에 필요합니다(없으면 음소거로 재생).
- 새 키오스크를 설치할 때: 관리자에서 키오스크를 추가하고 코드를 받은 뒤, 그 주소를 기기에 띄웁니다. 등록 안 된 코드로 열면 화면에 코드가 표시됩니다.

## 구조

```
server/
  index.js       Express 앱, 정적 파일
  db.js          SQLite 스키마
  admin-api.js   관리자 API (로그인 필요)
  kiosk-api.js   키오스크용 API: 설정 조회, SSE, 하트비트
  hub.js         SSE 연결 관리 (실시간 푸시)
  auth.js        관리자 세션
  seed.js        데모 데이터
public/admin/    관리자 SPA (빌드 불필요)
public/kiosk/    키오스크 플레이어
test/            API 테스트 (npm test)
```

데이터 모델: `buildings` → `floors` → `facilities` / `media` ← `playlist_items` → `playlists` ← `kiosks` / `notices`(대상: 전체·동·키오스크)

## 운영 시 참고 / 다음 단계 후보
- **HTTPS·리버스 프록시**: nginx 뒤에 둘 때 SSE 버퍼링을 끄세요(`X-Accel-Buffering: no`는 이미 보냄).
- **백업**: `data/kiosk.db`와 `uploads/`만 백업하면 됩니다.
- 이전 버전에 있던 대시보드·통계·긴급 송출은 뺐습니다(서버 시작 시 예전 데이터도 정리). 광고 송출 증빙이 필요해지면 통계를 다시 넣을 수 있습니다.
- 다음 단계 후보: 다중 관리자 계정·동별 권한, 시설별 모바일 길안내 QR.
